# Forge Neo NAG v0.5.0 — Qwen-Image 2512 native adapter

## 日本語

Qwen-Image-2512を含む**従来Qwen-Image系列のtxt2img（参照画像なし）**向けに、専用`QwenImageAdapter`を追加しました。Forgeの`QwenImage`エンジンからAuto判定し、手動選択にも対応します。

- Qwen2.5-VL 7Bの既存Text Encoderを再利用し、NAG Negativeを独立してエンコードします（安全上限2048トークン、切り詰めなし）。
- Qwen native `QwenImageTransformer2DModel.forward`・時刻条件・3軸RoPE・Image/Text別Projectionを維持します。
- Image Q/K/Vを共有し、Negative Textを各Blockで独立更新。NAGはImage Attention行だけに適用します。
- これまでの6アダプターにQwen-Imageを追加し、Auto／手動切替、CFG任意、通常Negative、Preset・Sampler非干渉を維持します。
- Qwen-Image-2.1は**非対応**です。**Qwen-Image-Edit-2511の画像参照・編集経路は今回有効化しません。** 正常なNative Edit一致・視覚品質・GPU Gateを完了してから別段階で対応します。編集状態はエラーで拒否し、通常NAG成功として扱いません。

CPU回帰テストは学習済みモデルを使わず、Native互換の小型モデルでAlpha=0一致、RoPE、画像Q/K/V共有、CFG・UNCOND維持、禁止条件、復旧を確認します。

**実Qwen-Image-2512チェックポイントでのGPU生成、画質・抑制効果、FP8・LoRA、VRAMは未検証です。** CPU回帰の成功をGPUでの品質保証として扱わないでください。

詳細：`docs/QWENIMAGE_IMPLEMENTATION.md`、`docs/VALIDATION_QWENIMAGE.md`

## English

Adds a dedicated `QwenImageAdapter` for **native Qwen-Image txt2img without reference images**, including Qwen-Image-2512.

- Auto-detect the loaded `QwenImage` engine, distinct from Qwen-Image-2.1.
- Reuse Forge Qwen2.5-VL 7B conditioning, native model forward, timestep and three-axis RoPE.
- Share native image Q/K/V; advance negative text per block; guide only image attention rows.
- Preserve user-controlled CFG, standard Negative, model preset, scheduler, sampler, steps and LoRA.
- **Qwen-Image-Edit-2511 reference/image-edit paths remain unsupported and are explicitly rejected** until a separate Phase B native-edit/GPU gate can be passed.

The CPU regression suite uses reduced random-weight contracts; it cannot establish pretrained-model GPU operation or image quality. FP8/quantized GPU, real LoRA, VRAM, quality and visual effect are unverified.
