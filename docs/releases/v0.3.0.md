# Forge Neo NAG v0.3.0 — Klein / Flux.2

## 日本語

`v0.2.0`のKrea2 / Anima / SDXL (Illustrious)対応に、**Klein / Flux.2** を追加したリリースです。

- Adapterに `Klein / Flux.2` を追加。Autoはロード済み `Flux2` エンジンから判定します。
- KleinのDoubleStream / SingleStream構造に合わせ、画像Q/K/Vを共有してText側だけNegative分岐を追加します。
- Forge Neo標準のQwen3 4B/8B text encoder、global modulation、4軸RoPE、`txt_ids_dims=[3]`を維持します。
- 通常CFG、標準Negative枝、Preset、sampler、scheduler、steps、解像度、Clip skip、LoRAはForge側の設定を維持します。
- KleinのReference/Edit、ControlNet、Hires、img2img、CFG++、token merging、Positive AND、既存Flux block/input patch、compiled modelは初期対応外です。
- Klein追加後のCPU自動試験: **315 passed / 0 failed**。

**実Klein 4B/9B GPU生成、BF16/FP16/FP8、実LoRA、画質、抑制効果、速度、VRAM/RAMは未検証です。**
CPU検証成功をGPU品質や性能の保証として扱わないでください。

詳細: `docs/KLEIN_IMPLEMENTATION.md` / `docs/VALIDATION_KLEIN.md`

## English

`v0.3.0` adds **Klein / Flux.2** to the existing Krea2 / Anima / SDXL (Illustrious) adapters.

- Adds `Klein / Flux.2` adapter and Auto detection from the loaded `Flux2` engine.
- Shares image Q/K/V and adds only the negative text branch across Klein DoubleStream and SingleStream blocks.
- Preserves Forge Neo's native Qwen3 4B/8B encoder, global modulation, four-axis RoPE and `txt_ids_dims=[3]`.
- Native CFG, standard negative branch, preset, sampler, scheduler, steps, resolution, Clip skip and LoRA remain user/Forge controlled.
- Klein Reference/Edit, ControlNet, Hires, img2img, CFG++, token merging, Positive AND, existing Flux block/input patches and compiled models remain unsupported initially.
- CPU validation after Klein: **315 passed / 0 failed**.

**Real Klein 4B/9B GPU generation, BF16/FP16/FP8, real LoRA combinations, image quality, suppression effectiveness, speed and VRAM/RAM remain unverified.**
