# Forge Neo NAG v0.5.1 — manual Adapter UI defaults fix

## 日本語

v0.5.0のメンテナンス更新です。**手動選択したAdapterをForge NeoのUI既定値として保存しても、再起動後にAutoへ戻る不具合**を修正しました。

原因は、NAG Dropdownが表示名（Krea2等）と内部ID（`krea2`等）を別々に使用していた一方、Forge Neo本体の`UiLoadsave.radio_choices()`が保存値を**表示名**と照合していたことです。

- Dropdownの値とUI既定値の保存は表示名へ統一しました。英語・日本語UIの7手動Adapterで保存・再読み込みを検証します。
- NAG内部処理、APIの7/8引数、PNG Infoの保存値は従来どおり安定した内部IDです。PNG Info復元時は表示名に変換してDropdownへ渡します。
- 無効なPNG Info Adapter選択は従来どおりAutoへ戻します。Forge本体の変更やグローバルなUI monkey-patchは行っていません。
- **以前の`ui-config.json`に内部IDで保存された選択は、自動移行しません。** アップデート後にAdapterを選び直し、Forge UI既定値管理から再保存してください。拡張が設定ファイルを書き換えることはありません。
- 既存の7モデル、NAG数式、CFG、Sampler、Preset、標準Negativeは変更しません。Qwen-Image-Edit-2511のD0～D4は保留を維持します。

テストはGradio上でForge UI既定値の表示名照合規約を再現します。実GPU生成・画質・VRAM・実LoRA／量子化は本リリースの検証対象外です。

## English

Maintenance fix for v0.5.0: **manual Adapter selection no longer resets to Auto when persisted through Forge Neo UI defaults**.

Forge's `UiLoadsave.radio_choices()` validates saved Dropdown values against choice **labels**, while the old NAG UI supplied stable adapter IDs as Gradio values. The UI now uses display labels as its values; NAG still normalizes to stable IDs for execution, API and PNG Info metadata.

- Adds English/Japanese save-and-reload tests for all seven manual adapters, plus metadata, API and invalid-choice checks.
- PNG Info stores the original stable adapter IDs; restore converts them to visible labels.
- Legacy internal-ID values in an old UI defaults file may need a one-time re-selection and re-save. No automatic user-config mutation.
- No model or sampler changes. Forge Neo core is untouched. Edit-2511 remains deferred.

CPU regression tests are run separately; this maintenance fix is not a GPU or image-quality validation.
