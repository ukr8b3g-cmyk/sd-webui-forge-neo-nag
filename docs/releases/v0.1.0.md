# Forge Neo NAG v0.1.0

## 日本語

Forge Neo向けNormalized Attention Guidance拡張の初期版です。拡張可能なモデル別構造を持ち、
**V1の対応モデルはKrea2のみ**です。

- 標準Negative Promptとは独立したNAG Negative Prompt入力欄。
- CFG=1.0でのAttention内部NAG。初期値はPhi=4.0 / Tau=2.5 / Alpha=0.25。
- 画像Q/K/Vの共有と、サンプリング中限定のNegativeテキスト変換キャッシュ。
- 日英README、言語設定に対応するUIラベル・マウスオーバーヘルプ。
- 生成情報の保存とPNG Info復元、無効化・例外・中断時の状態復旧。

**実装とCPU検証済み、実モデルでのGPU生成は未検証です。** 前回の実装検証記録では回帰試験154件、
Forge定義を使う小型CPU試験24件、日英ヘルプのブラウザー試験16件が通過しています。
公開準備では実装コードを変更せず、Python／JavaScript構文と配布ZIPの内容・整合性を確認しました。
公開環境には試験用ライブラリがないため、上記試験の再実行はしていません。
画質、抑制効果、GPU速度・VRAM、FP8・LoRAの組合せ、実際のForge画面は未確認です。

対応範囲は**Krea2 / txt2img / CFG=1 / 参照画像なし**です。Reference/Edit、img2img、
Hires fix、CFG++、他のAttention・Guidanceパッチとの併用はV1では非対応です。

`sd-webui-forge-neo-nag-v0.1.0.zip`を展開し、Forge Neoの
`extensions/sd-webui-forge-neo-nag/`へ配置してWebUIを再起動してください。
ComfyUIの`custom_nodes`には配置しません。追加の実行時依存関係やモデルのインストールは不要です。
詳しい操作はREADME、実機確認は`docs/GPU_CHECKLIST.md`を参照してください。

## English

Initial release of Normalized Attention Guidance for Forge Neo. Model adapters are
extensible; **Krea2 is the only supported model in V1**.

- Dedicated NAG negative prompt, separate from the standard negative prompt.
- Attention-space NAG at CFG=1.0; defaults: Phi=4.0, Tau=2.5, Alpha=0.25.
- Shared image Q/K/V and sampling-local negative text-fusion caching.
- English/Japanese README, localized UI labels and mouse-over help.
- Generation metadata, PNG Info restoration, and cleanup on completion/error/interruption.

**Implementation and CPU validation are complete; pretrained-model GPU validation
is pending.** Existing implementation records show 154 regression tests, 24 reduced
native-definition CPU checks and 16 browser tooltip checks passing. Release
preparation preserves the runtime code and checks Python/JavaScript syntax and ZIP
contents/integrity. The full suites were not rerun in the publishing environment,
which lacks their development libraries. Visual suppression, image quality, GPU
speed/VRAM, FP8/LoRA combinations and the user's native Forge UI remain unverified.

V1 supports **Krea2, txt2img, CFG=1, no references**. Reference/Edit, img2img,
Hires fix, CFG++ and other attention/guidance patches are outside V1 scope.

Extract the ZIP into `extensions/sd-webui-forge-neo-nag/` in Forge Neo and restart
the WebUI. Do not install it in ComfyUI's `custom_nodes`. No additional runtime
dependencies or model weights are installed. See the README and
`docs/GPU_CHECKLIST.md` for use and real-environment verification.

The ZIP includes `BUILD_INFO.json` identifying its source commit. A SHA-256
checksum file is provided alongside it. Upstream credits and license notices are
preserved in `NOTICE.md`, `LICENSE` and `licenses/`.
