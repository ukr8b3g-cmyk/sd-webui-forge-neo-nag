# Forge Neo NAG v0.4.2 — Z-Image / Ernie safety and RoPE regression maintenance

## 日本語

v0.4.1からのメンテナンス版です。モデル対応範囲、NAG数式、Forge標準CFGの扱いは変更しません。

- **F01：接続後の競合検知**：Z-Image / ErnieのBlock・AttentionがNAGの接続後に変更された場合、実行時契約を再検査して明示的に拒否します。これはmainに先行反映済みで、v0.4.2で正式Releaseへ取り込みます。
- **F02：RoPE試験補強**：Ernieの座標加算による代用を実際のsplit-half 2×2回転行列へ変更。Z-ImageのCPU試験もComfy-Kitchenのinterleaved-pair回転に修正。画像Q/K/V共有、遅延Block/Attention変更の回帰試験を追加します。
- **F03：ドキュメント修正**：READMEの旧Krea2専用・CFG=1必須・UI7項目記述を修正し、6モデル・CFGユーザー設定・UI8項目・モデル別トークン上限へ統一。対応モデル一覧の古いラベルも修正。

Native ForgeのPreset、CFG、sampler、scheduler、steps、LoRA、標準Negative入力は拡張が変更しません。初期対象はtxt2img（参照画像なし）です。

ローカルではRoPE数値オラクルと修正キット適用試験が成功しています。**今回のリリースに対するフルpytestの再実行、および実Z-Image/Ernie学習済みモデルのGPU生成・LoRA・量子化・画質・VRAM評価は未実施です。** GitHub Actionsの配布チェックはPython/JavaScript構文とZIP内容・checksumの確認であり、GPU検証を意味しません。

## English

Maintenance release from v0.4.1. Supported model families, NAG mathematics, and Forge's native CFG ownership are unchanged.

- **F01: Late mutation guard:** reject Z-Image/Ernie block or attention mutations introduced after NAG installation, including the previously committed main-branch fix.
- **F02: RoPE regression tests:** replace Ernie's additive test double with split-half 2×2 rotary matrices and Z-Image's test double with Comfy-Kitchen-style interleaved rotary pairs. Add checks for shared image Q/K/V at attention inputs and late module/class mutations.
- **F03: Documentation:** remove stale Krea2-only / CFG=1 / seven-control README instructions; document six adapters, user-controlled CFG, eight UI inputs and model-specific token limits. Update stale adapter integration labels.

Forge continues to own presets, CFG, samplers, schedulers, steps, LoRA and the standard Negative Prompt. Initial common scope is txt2img without reference images.

CPU math-oracle and patch-application smoke tests were run. **A complete pytest rerun of this release and real pretrained Z-Image/Ernie GPU tests for image quality, LoRA, quantization and memory have not been performed.** The release workflow verifies Python/JavaScript syntax and the built ZIP/checksum only.
