# Forge Neo NAG v0.4.0 — Z-Image Turbo + Ernie Image

## 日本語

`v0.4.0`は、`v0.3.0`のKrea2 / Anima / SDXL (Illustrious) / Klein (Flux.2)に、**Z-Image Turbo (ZIT)** と **Ernie Image** を追加します。

- ZIT専用 `ZImageAdapter`：NextDiT Joint Attention、共有Image Q/K/V、Hybrid RoPE。
- ZIT Noise Refinerへ、Forge本体と同じ計算済み `adaln_input` を渡す契約修正を反映。
- Ernie専用 `ErnieAdapter`：native `Ministral3Engine`、`[Image | Text]` Joint Attention、共有Image Q/K/V、Hybrid RoPE。
- Auto判定と手動Adapter選択へZIT/Ernieを追加。
- CFGはユーザー設定を維持し、標準Negative枝と最終CFG合成はForge本体に任せます。
- Preset、sampler、scheduler、steps、解像度、Clip skip、LoRAをNAG側から自動変更しません。

現在の共通初期対応は **txt2img / 参照画像なし** です。Hires fix、img2img、ControlNet、CFG++、token merging、Positive AND、compiled model、競合Attention/Guidance patchなどは対象外です。

**ZIT/Ernieの実モデルGPU生成、BF16/FP16/FP8・量子化、実LoRA、画質、抑制効果、速度、VRAM/RAMは未検証です。**
公開ワークフローはPython構文、JavaScript構文、配布ZIP内容・整合性を確認します。これはpytest全再実行やGPU品質検証の代替ではありません。

詳細: `docs/ZIMAGE_IMPLEMENTATION.md`, `docs/VALIDATION_ZIMAGE.md`, `docs/ERNIE_IMPLEMENTATION.md`, `docs/VALIDATION_ERNIE.md`

## English

`v0.4.0` adds **Z-Image Turbo (ZIT)** and **Ernie Image** to the v0.3 Krea2 / Anima / SDXL (Illustrious) / Klein (Flux.2) adapter set.

- ZIT-specific `ZImageAdapter`: NextDiT joint attention, shared image Q/K/V and Hybrid RoPE.
- Includes the ZIT noise-refiner contract fix that passes the already-computed `adaln_input`, matching native Forge `NextDiT.forward`.
- Ernie-specific `ErnieAdapter`: native `Ministral3Engine`, `[Image | Text]` joint attention, shared image Q/K/V and Hybrid RoPE.
- Adds ZIT and Ernie to Auto routing and manual adapter selection.
- Native Forge CFG, standard negative branch and user generation settings remain authoritative.
- NAG does not rewrite preset, sampler, scheduler, steps, resolution, Clip skip or LoRA.

Initial common scope remains **txt2img with no reference images**. Hires fix, img2img, ControlNet, CFG++, token merging, Positive AND, compiled models and conflicting attention/guidance patches remain unsupported.

**Pretrained ZIT/Ernie GPU generation, BF16/FP16/FP8 or quantized execution, real LoRA combinations, image quality, suppression effectiveness, speed and VRAM/RAM remain unverified.**
The release workflow checks Python/JavaScript syntax and ZIP integrity/content; it is not a substitute for a full pytest rerun or pretrained-model GPU validation.
