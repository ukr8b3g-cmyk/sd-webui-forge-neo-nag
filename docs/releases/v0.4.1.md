# Forge Neo NAG v0.4.1 — Sparse Attention + Adapter restore fixes

## 日本語

`v0.4.1`は`v0.4.0`のメンテナンスリリースです。モデル対応範囲やNAG数式は変更せず、CPU総検証で確認された2件の不具合を修正します。

- **Sparse Attention競合修正**：Forgeの`optimized_attention_override`が有効な場合、NAGは事前検査およびサンプリング中の再検査で明示的に拒否します。Z-ImageでTypeErrorまで進む経路、Klein/Ernieで無検出のまま処理される経路を防ぎます。
- **手動Adapter保存・復元修正**：表示名と内部IDを共通レジストリで正規化し、保存は安定した内部ID、復元は内部ID/表示名のどちらからでも可能にしました。
- 対応Adapterは従来どおり `Krea2 / Anima / SDXL (Illustrious) / Klein (Flux.2) / Z-Image Turbo (ZIT) / Ernie Image`。
- CFG、標準Negative、Preset、sampler、scheduler、steps、解像度、Clip skip、LoRAの所有権はForge/ユーザー側のままです。

今回の修正用回帰テストには、Sparse Attentionの事前/後付け競合、および6 Adapter × 英語/日本語の手動復元ケースを追加しています。

**実モデルGPU、画質、VRAM、量子化、実LoRA、実生成キャンセル復旧は引き続き未検証です。**

## English

`v0.4.1` is a maintenance release for `v0.4.0`. It keeps the model support and NAG math unchanged while fixing two issues found during CPU validation.

- **Sparse Attention conflict fix:** NAG now rejects Forge's `optimized_attention_override` both at preflight and if it appears after installation during sampling.
- **Manual Adapter restore fix:** display labels and stable internal IDs are normalized through one registry mapping. Metadata continues to store stable IDs, while restore accepts either IDs or display labels.
- Supported adapters remain `Krea2 / Anima / SDXL (Illustrious) / Klein (Flux.2) / Z-Image Turbo (ZIT) / Ernie Image`.
- CFG, standard Negative, preset, sampler, scheduler, steps, resolution, Clip skip and LoRA remain Forge/user controlled.

Regression coverage was added for Sparse Attention preflight/late conflicts and all six manual adapters across English/Japanese restore cases.

**Real-model GPU generation, image quality, VRAM, quantization, real LoRA and cancellation recovery remain unverified.**
