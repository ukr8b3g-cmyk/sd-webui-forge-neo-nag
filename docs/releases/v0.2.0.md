# Forge Neo NAG v0.2.0

## 日本語

Krea2専用だった初期版から、**Anima** と **SDXL / Illustrious** を追加したマルチアダプター版です。

- Adapter: `Auto / Krea2 / Anima / SDXL (Illustrious)`
- 手動アダプター選択を追加。Auto判定が意図と違う場合はユーザーが修正可能
- **CFG=1固定を撤廃**。通常Negative枝とForge本来のCFG合成を維持
- Preset、CFG、sampler、scheduler、steps、解像度、Clip skip、LoRAはNAG側から変更しない
- AnimaはCross-Attention、SDXL / IllustriousはUNet `attn2`へモデル別に接続
- 既存Krea2経路とNAG数式は維持
- PNG Info / メタデータへ選択アダプターと実適用モデルを記録
- CPU自動試験: **300 passed**

現在の共通対応範囲は **txt2img / 参照画像なし** です。Hires fix、img2img、Refiner、ControlNet、IP-Adapter、CFG++、Tiling、Token merging、領域/Positive AND合成、動的LoRA、追加Attention/Guidanceパッチ、torch.compileは対象外です。

**実モデルGPU生成、FP8/量子化GPU、実LoRA組合せ、画質、抑制効果、速度、VRAM/RAMは未検証です。**

## English

Multi-adapter release adding **Anima** and **SDXL / Illustrious** to the original Krea2 support.

- Adapter selector: `Auto / Krea2 / Anima / SDXL (Illustrious)`
- Manual adapter override when Auto is not the desired choice
- **CFG=1 restriction removed**; native Forge unconditional branch and CFG composition are preserved
- NAG does not rewrite preset, CFG, sampler, scheduler, steps, resolution, Clip skip or LoRA
- Model-specific Cross-Attention integration for Anima and SDXL
- Existing Krea2 adapter and NAG math retained
- Adapter/model metadata and PNG Info restoration
- CPU validation: **300 passed**

Current common scope is **txt2img with no reference images**. Hires fix, img2img, Refiner, ControlNet, IP-Adapter, CFG++, tiling, token merging, regional/Positive AND composition, dynamic LoRA, other attention/guidance patches and torch.compile remain unsupported.

**Pretrained-model GPU generation, FP8/quantized GPU execution, real LoRA combinations, image quality, suppression effectiveness, speed and VRAM/RAM remain unverified.**
